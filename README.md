ThoughtBox provides an AI‑native application platform that connects large language models to enterprise data sources such as cloud storage, email, calendar, and finance systems. It offers ready‑made connectors (Google, Microsoft, Box, Dropbox, Plaid) and lets developers compose capabilities without rebuilding infrastructure. Users can deploy via web, AI agents, or API, with in‑account deployment for enterprise security.

**Areas:** AI · Platform · Integration · Enterprise · Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ThoughtBox: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
